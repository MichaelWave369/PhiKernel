PhiKernel is part of the **Phi Commons**.

Unless a file or directory says otherwise, original PhiKernel software and documentation in this repository are released under the MIT License in `LICENSE`.

## What this means

People may inspect, use, copy, modify, merge, publish, distribute, sublicense, and sell copies of project-owned PhiKernel code subject to the MIT notice requirements.

The Commons grant does not replace or override licenses attached to third-party dependencies, copied upstream code, model weights, datasets, fonts, media, trademarks, or other separately licensed material.

## Runtime sovereignty remains separate from source licensing

Opening the code does not weaken PhiKernel's authority model.

The project continues to treat these as distinct:

- capability is not authority;
- cryptographic identity is not a permission grant;
- routing is not authorization;
- local continuity does not imply external control;
- no subsystem gains privilege merely because the source code is available.

## PhiOS relationship

PhiKernel is a runtime/substrate donor and implementation lineage for PhiOS.

Open licensing allows PhiOS and other free systems to reuse the good parts cleanly. It does not require PhiOS to preserve every historical PhiKernel API, identity, or architecture.
