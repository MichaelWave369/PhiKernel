# PhiKernel License History

## Proprietary era

PhiKernel was originally maintained as private proprietary software with an all-rights-reserved notice.

The exact pre-Phi-Commons repository state is preserved at:

```text
archive/pre-phi-commons-license-2026-09-17
```

and commit:

```text
b444a761500a00134d20740eb5c41ae92f134cbe
```

The historical proprietary notice is preserved in that branch and in Git history.

## Phi Commons / MIT era

Beginning with the Phi Commons migration, project-owned PhiKernel code and documentation are released under the MIT License unless otherwise noted.

Third-party dependencies remain under their upstream licenses.

## Provenance rule

Licensing history is part of provenance. The project preserves the old state rather than rewriting it.
